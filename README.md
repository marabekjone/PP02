# PP02 — Система распознавания и обработки документов (OCR)

## О проекте

Данный проект разработан в рамках производственной практики ПП.02 студентом группы **09.02.07-3ПА**  
**Османов Магомед Асланович**  

База практики: **ИП Горинов Всеволод Игоревич**

Программа предназначена для автоматизации обработки документов, распознавания текста с изображений (OCR), хранения результатов и поиска информации.

---

## Функциональные возможности

Программа позволяет:

- загружать изображения и документы;
- распознавать текст с помощью OCR (Tesseract);
- сохранять результат в базу данных;
- искать документы по содержимому;
- экспортировать текст в файл;
- удалять документы из базы данных.

## Установка и запуск

### 1. Установить Python

Скачать: https://www.python.org/

---

### 2. Установить Tesseract OCR

Скачать: https://github.com/tesseract-ocr/tesseract

После установки убедиться, что путь указан в `ocr.py`:

```python
pytesseract.pytesseract.tesseract_cmd = r'C:\Program Files\Tesseract-OCR\tesseract.exe'
```

3. Установить зависимости
В папке проекта выполнить:

```bash
pip install -r requirements.txt
```

4. Создать базу данных

```bash
python init_db.py
```

5. Запуск распознавания текста

```bash
python ocr.py
```

6. Поиск документа

```bash
python search.py
```

7. Экспорт результата

```bash
python export.py
```

8. Удаление документа

```bash
python delete.py
```
